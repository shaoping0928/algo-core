### 通用上下文与分层记忆（2026-11-21，第一片）

不做任何物理量专用方案：世界侧只改变隐藏动力学，学习器只见
`obs / action / next_obs / feedback`。

**上下文层**（`context_model.py`）：共享线性世界模型 + 训练流按固定窗
（默认 800 帧）切段，每段估残差修正；对修正向量做**中位距离凝聚聚类**
发现 regime（本例 8 个训练世界 → 9 个发现组，**未给 world 标签、无顺序
假设**）；组中心做 PCA，保留残差谱中显著的方向；运行时用最近真实转移
的岭回归**在线推断**上下文系数；残差监测器在 regime 变化时丢弃过期缓
冲、重置快通道。慢结构保持 1/n，快通道临时适应。

**分层记忆**（`memory_tree.py` / `hierarchical_memory.py`）：

```text
L0 帧窗（几帧） → L1 关键事件 → L2 阶段 → L3 世界 → L4 根
```

低层按时间邻接分段，高层按世界签名聚类。父节点是**有损段落概括**：
子节点加权 PCA 的 `keywords`（核心方向）+ `residual`（省略的细节）+
`expand()` 重建子节点；关系记为 `summarizes` / `part_of`。关键词跨
兄弟节点比较 → 共享的是**持久概念**，只在一个父节点出现的是**临时细节**。

**变量关系结构**（`variable_registry.py`）：每个变量带
`support / variance / timescale / credibility / learning_rate`；关系
`part_of / tracks / competes / summarizes`。慢变量
`lr = 1/(support + 父支持 + prior)`；快变量 lr 由父可信度和持久度调制；
父可信度提高子可信度。

**探针**（`dynamics_context_probe.py`，世界侧同时变化四个隐藏因素：
重力、拍翅冲量、阻力、管道速度；学习器一个都看不到；8 训练世界 ×
4 未见世界，含中途切换）：

| 指标 | 结果 |
|---|---|
| 上下文层一步预测误差（4 个未见世界） | **0.0033 / 0.00215 / 0.00519 / 0.00476** |
| 全局模型同协议 | 0.0058 / 0.00477 / 0.00728 / 0.00662 |
| 隐藏相关（诊断，不被学习器使用） | z0-g 0.39；z1-flap −0.66、z1-speed 0.73；z2-flap 0.57；z3-flap 0.46 |
| 世界树 | 8 叶 / 4 个父概括；父节点 1 个关键词，`expand` 重建误差 ~0 |
| 关键词持久性 | 跨兄弟相似度 0.41/0（尚未稳定） |
| 阶段概括 | 平均残差 4.3e-7、重建误差 3.2e-4 |
| 记忆先验（context+mem） | **首版中性偏负**：2/4 持平、2/4 略差；先验查询/精度未校准 |

**4/4 未见世界改善，约 1.4–2.2×**；发现组数（9）没有被告知，来自残差
修正的聚类。上下文维与多个隐藏因素相关，没有一个“重力专用维度”。
变点检测只在残差超过内世界阈值时触发；部分切换被快通道直接吸收，
无需重置——这是期望行为，不是所有变化都需要新 regime。
**当前可宣称的是上下文层本身；分层记忆的概括/展开/持久性已跑通，
但记忆先验还没有转成收益。** 测试 183。

### 生成式展开（2026-11-21，第一片）

父节点关键词作为**提示**，而不是只用于重建：

```text
关键词 summary → 上下文 prompt
              → 记忆中最接近的已存帧作为起点
              → 节点系统学到的 feature risk/value 单步策略
              → 上下文层 rollout（越界/非有限即停）
              → 新的近似阶段流（不是复制子节点）
```

4 个世界父概括，关键词 prompt vs 全局零 prompt，生成观测到该世界已存帧的
最近邻距离：

| 父节点 | 层级 | 关键词距离 | 全局距离 | 改善 | 步数/阶段 |
|---|---:|---:|---:|---:|---:|
| 3 | 1 | 0.1825 | 0.1981 | +0.0157 | 18 / 3 |
| 6 | 1 | 0.0961 | 0.1081 | +0.0120 | 18 / 3 |
| 9 | 1 | 0.3338 | 0.5998 | +0.2660 | 11 / 2 |
| 10 | 2 | 0.2836 | 0.5415 | +0.2579 | 11 / 2 |

**4/4 关键词 prompt 更接近目标世界的已存记忆，生成流全部有限。**
限制：单步 cell 策略不是完整 planner；世界签名仍 noisy；越界即停；
尚未用生成流初始化新世界的 planner/上下文先验，也还没有生存指标。

### 生成先验的配对实验（2026-11-21）

`generated_prior_probe.py` 把生成流变成**决策先验**：新世界先跑 10 帧
固定 warmup，然后用相同动作分叉三臂：

```text
global     清空上下文，从零开始
online     warmup 自己的上下文估计
generated  用 warmup 动作对每个记忆候选做生成模拟，
           选预测最匹配的 regime 作为 context prior
```

**通用置信度门控**：只有最佳候选相对第二名有明显优势
（`(second-best)/second ≥ 0.05`）才采用生成先验；否则回退 `online`。

单流首轮（model_seed 200）：vs global **+59.0（8/8 正向）**，
vs online **+72.9（7/8 正向，1 平）**。但 **3 个行为流种子
（100–102，各 8 episode，共 24 配对）没有复现**：

| 对比 | 逐种子均值 | 合计均值 | 中位 | 正向 |
|---|---|---:|---:|---:|
| vs global（零上下文） | +15.6 / +18.5 / −13.5 | **+6.9** | 0 | 11/24 |
| vs online（warmup 上下文） | +8.4 / −6.6 / +9.9 | **+3.9** | 0 | 3/24（12 平） |

**判定：单流的 8/8 是流彩票，生成先验的生存收益不成立。**
门控接受 5–6/8、回退 2–3/8；接受先验也常被 planner 的 ±100 帧噪声
淹没。第一次 3 种子跑出逐位相同的 24 配对——训练行为流没有随模型
种子变化（协议 bug）；改为 `behavior_seed = data_seed*1e6 + world_seed`
后重跑，才有上述结果。
**保留的已验证部分**：上下文层对未见动力学的预测误差 2–3× 改善
（无 world 标签）；分层概括/生成式展开的匹配机制。
**不再宣称**：生成先验提高存活。

**预测可信度加权（第二波）**：候选距离改为
`distance × (1 + (1 - credibility))`，并加 `credibility ≥ 0.4` 门；
预测节点优先特征根，根不激活时回退最近原型。3 种子：

| 对比 | 逐种子均值 | 合计 | 中位 | 正向 |
|---|---|---:|---:|---:|
| vs global | +15.6 / +9.0 / −13.5 | **+3.7** | 0 | 10/24 |
| vs online | +8.4 / −16.1 / +9.9 | **+0.7** | 0 | 3/24（11 平） |

接受 17/24、回退 7/24，候选平均 credibility 0.73。**仍是 null**；
预测通道本身有信号（5–12 节点/episode、0.70–0.81），但没把先验
变成可靠收益。保留为诊断/学习率信号。

### 多分支节点系统（2026-11-21，第一片）

同一张 `NodeGraph`，每个角色拥有自己的稀疏强度字典：

```text
CurrentBranch      瞬时现状（覆盖上一帧）
RecentBranch       指数衰减近期痕迹
PredictionBranch   rollout 的预期激活，compare(current) 逐节点误差
ValueBranch        慢速价值（固定率或 1/n）
BranchBank         transition_pairs / prediction_error / snapshot
```

`BranchBank.transition_pairs(action)` 用 `recent × current` 生成
`(old, action, new)` 的加权证据，供动作边学习；`prediction_error()`
把预测分支与现状分支逐节点比较，供预测可信度/学习率使用。

**只读接入**：`NodeRuntime._interact` 每步更新 `current`/`recent`，
决策路径仍读原有图字段。同一 fast 配置的 80 帧评估与接入前**逐位
相同**；测试 188 → 196（+8 branch）。下一步：转移边学习、
prediction 分支、记忆树分支关键词、value/risk 分支接入。

**预测分支（第二片）**：`evaluate` 在 `env.step` 前用 `world.predict`
记录下一状态的根激活，step 后与真实下一状态比较；每个预测根维护
`precision = (hits + prior*base)/(count + prior)` 与
`learning_rate = 1/(count + prior)`，`run_seed` 输出 prediction summary。
80 帧评估仍与接入前逐位相同；测试 **197**。下一步：用逐节点
credibility 门控生成先验/预测读取，做 3 种子 A/B。

**转移学习（第三片）**：`--branch-transitions` 把衰减的 `recent`
来源以 `weight × 0.25` 追加到动作边证据；`recent` 现在表示离开的状态，
`current` 表示进入的状态。但动作边 Q 仍不被 planner 读取，所以
on/off 的 80 帧评估**逐位相同**——这是结构学习，不是生存增益。
测试 **199**。接线 Q 之前不宣称生存收益。

**动作边 Q 接入 planner 的裁决（2026-11-21）**：
`--action-edge-weight 0.1 --action-edge-trust 50` 给 planner 加第 6 列
Q（归一化 + `count/(count+50)` 信任）。3 种子 × 5 held-out：
control **152.9** / 中位 152；Q **99.6** / 中位 72；配对
−125.2 / −70.8 / +36.2，均值 **−53.3**，仅 1/3 正向。
**当前 Q 构造负向；默认权重保持 0（opt-in）**。fast 屏
133.8 vs 112.8 没有复现——又一次流彩票。Q 读路径保留为 opt-in，
不再宣称生存收益。

**target-conditioned Q（2026-11-21）**：改为精确
`(前一原型, 下一原型, acting)` 边（planner 闭包逐步保存前一状态）。
3 种子：Q **117.5** / 中位 145 vs control **152.9** / 中位 152；
配对 −54.4 / −35.4 / −16.2，均值 **−35.3**，**0/3 正向**。
目标条件修复把均值从 99.6 抬到 117.5，但没有转正。
**Q 方向关闭（目标平均 + 目标条件双负）**，默认权重 0，保留为诊断。

### 帧级失败追踪（2026-11-21，`learning_trace.py`）

只读包装器跑真实基准（1500×1 + 5000 帧 DAgger，seed 100），在
held-out 120–124 上逐帧记录决策，抽取随机帧 + 死亡窗口；另对训练流中
的死亡 episode 做更新前后快照。结论：

- **学习确实发生**：离线→DAgger 后节点 1547→1802、动作边 1045→1092、
  记忆 21→55；held-out 均值 **86.2→191.8**（中位 72→152）。单个
  72 帧 planner 死亡 episode 写入 **66 个带值新原型、51 条新动作边**，
  既有边 Q 也移动（+0.045）。
- **失败窗口两类**：
  - **盲死**：最近原型距离 ~1.0–1.6，窗口内 risk/根/记忆全 0，
    死亡帧也只读到 0（world 123）或 0.8（world 124）；
  - **有信号但饱和**：horizon 危险 2.3→**5.0**（4 个 stride 读 +
    终端，每项 ≤1 的结构上限），到顶后所有计划同分，动作退化为默认 0；
    此前一直偏好不拍翅（a=0），唯一拍翅是 −0.016 的近似平局。
  - 失败点常离原型 **3.3–4.5**（出生阈值 0.45），世界模型误差
    0.14/0.455（同分布 1e-3 量级）→ 危险场是外推。
- **动作条件化缺失**：`epochs=1` 下特征动作格 = 0，同一预测状态的
  拍/不拍读出相同；价值列恒 0、Φ≡1（见上节），记忆检索 0–4%、
  死亡帧仅 1 条权重 0.01。
- **跨阶段非单调**：phase 1 在 phase 0 的死亡状态上更近
  （4.46→1.10），但旧静态规则读出 0.8 危险、新特征库读 0；世界 123
  从 143 退到 80。DAgger 换掉了特征库，覆盖不是只增不减。
- **评测期没有在线学习**：死亡反馈只在下一次批量/DAgger 重训时进入；
  若该状态未被新数据覆盖，更新落在新生原型上，不回到决策状态。
- **oracle 反事实（真实世界枚举动作序列）**：phase 0 world 124 在
  t≤65 仍有存活序列（t=66 起无解），规划器 t=65 选 0、t=66 才拍 1，
  已晚一帧；phase 1 world 123 在 t≤76 仍有存活序列（t=77 起无解），
  规划器 t=76 仍选 0。**拯救动作存在，模型没看见**；最后机会点的
  选择直接致命。

判定：批量 MC 的原型/边/记忆学习是真实的；失败帧的决策没有被这些
学习有效改善。瓶颈是**特征动作格断线 + 危险饱和 + OOD 外推**，不是
“没有更新”，也不是“无解”。`learning_trace.py` 保留为诊断工具。

### 0/1 死亡条件规则（2026-11-21，Batch 1）

`death_rules.py` 不再把 pain 平均成概率：输入是 entered state 的
0/1 终止标签，输出是**纯 0/1 规则或 `UNKNOWN`**。归纳用
separate-and-conquer/AQ：每条规则从正例种子出发，选择“保留最多正例、
排除最多反例”的合取，规则必须零假阳；覆盖的正例移除后继续下一条。
安全类同样归纳，所以状态可以回答 1（死）、0（安全）或 `UNKNOWN`
（证据不足，等反例，不给概率）。

`rule_expressions.py` 预留多算子组合：n 元 `AND/OR/XOR`、`NOT`、
数值项（和/差/积/min/max/mean/比值/abs）与阈值比较；当前 AQ 只是其中
一个搜索算子，组合搜索已能恢复合成的 XOR/NOT 规则。任务无关：只用
`f0..f_{d-1}` 和标签，无任务词汇。

真实流探针（`death_rule_probe.py`，seed 100，1500 帧，行为流）：

- 规则自动发现两个模式：`dims=(0)` 的边界条件、`dims=(2,3)` 的侧向
  条件；训练/留出 episode 全对。
- 初始侧向规则 `f2 < 0.065` 过宽；在 120–121 世界上加 51 个反例后，
  测试 122–124 从 **34 TP / 32 FP** 变为 **34 TP / 0 FP / 0 FN**，
  规则细化为 `|f3| > 0.248 AND |f2| < 0.065`。
- 再在 planner 轨迹上加 2 个反例，阈值细化为
  `|f3| > 0.173 AND |f2| < 0.065`；planner 测试的 3 个终止状态全部
  被规则捕获，0 safe / 0 unknown。
- 这仍是离线验证，没有接决策；Batch 2 才做 planner 的硬约束
  （每步检查、首次死亡时间排序）与真实基准 3 种子 A/B。

### 0/1 死亡条件硬约束（2026-11-21，Batch 2）

`--death-rules` 在 `_train` 末尾用 entered state 的 0/1 终止标签训练
`DeathRuleSet`，挂到 `agent.death_rules`。`exhaustive_search` 新增
`evaluate_death`：每个预测步检查规则，命中即计划不可行（不改 stride、
不改账本列）；若所有计划都不可行，按**首次死亡步最晚**选择，再按原
目标排序。`UNKNOWN` 不当作死亡，回退到原 hazard 目标。默认关闭；
`evaluate_death=None` 时搜索路径逐位不变（214 测试）。

**真实基准两臂 × 3 种子（1500×1 + 5000 DAgger，eval 120–124）**：
control `191.8 / 178.4 / 88.4`，均值 **152.9**，中位 152；
`--death-rules` `206.2 / 94.8 / 118.2`，均值 **139.7**，中位 117。
配对 Δ **+14.4 / −83.6 / +29.8**，均值 **−13.2**，2/3 正向。
**判定：硬否决不采纳为默认（均值负向，seed 101 大幅回退）；
`--death-rules` 保留 opt-in。** 下一步不再调 veto，而是测死亡转移
判断本身的质量（`f` 与 `T` 分解、首死步误差、动作对比正确率）。

### 死亡转移质量（2026-11-21，`death_transition_quality.py`）

只读探针：真实基准训练一次，在 120–124 的控制策略轨迹上采样 170 个
`(state, action)` 分支，用真实世界做 oracle，分别测 `f` 与 `T`。
关键读数：

| 口径 | TP | FP | FN | unknown |
|---|---:|---:|---:|---:|
| 规则 / 真实下一状态（完整） | 8 | 0 | 2 | 0 |
| 规则 / 真实下一状态（只判死） | 8 | 0 | 0 | 162 |
| 规则 / `f` 预测状态（只判死） | 6 | 0 | 0 | 164 |
| hazard / 真实下一状态 | 8 | 10 | 2 | — |
| hazard / `f` 预测状态 | 8 | 5 | 2 | — |

- 多步首死（H=8）：hold 78 个真实死亡中 **22 FN**，flap 10/87，
  alternate 15/81；首死步全对 128/170，误差 ≤1 为 138–141/170。
- 状态预测误差：均值 0.0015、最大 0.0137；横向相关维约 0.0043。

  `f` 的误差再把 2 个终止状态从已覆盖变成 unknown。下一步是覆盖率

### 覆盖率优先与边界余量（2026-11-21，Batch 3）

- **覆盖率优先**：对未覆盖训练正例用更大合取预算/组合搜索继续生长。
  合成测试通过（3 文字合取、XOR 组合）；真实训练流本身已 100/100
  覆盖、0 FP，因此该 pass 没有改变 held-out 的 8/10 终止覆盖——
  缺的是泛化，不是训练规则预算。
- **两个 unknown 终止的定位**：一个是 `|f3|` 恰在阈值边界
  （0.176229 vs 阈值约 0.176）；另一个是 `f2` 被 `f` 的误差从 0.060
  推到 0.067，越过 `|f2|<0.065`。两者都是边界/模型误差，不是模式缺失。
- **边界余量**（`--death-rule-margin 0.01`，按坐标观测范围取比例）：
  死亡阈值附近返回 `UNKNOWN`，安全规则不能在那里声称安全。完整分类
  从 **8 TP/0 FP/2 FN** 变为 **8 TP/0 FP/0 FN/14 unknown**；
  死亡侧与首死召回不变（8/10、6/10，首死 FN 仍 22/10/15）。
  判定：余量是**安全声明**的修复，不是召回修复。
- **上下文分桶**（`contextual_rules.py`）：按调用方给的标量上下文
  （残差/距离/未知度）分桶，正例太少的桶回退全局；合成测试中两个
  上下文的不同死亡条件均零 FP/FN，稀疏桶回退正常。尚未接真实残差，
  也未接 planner。
- 结论：当前质量门仍卡在**召回/覆盖**；下一步做 model-error-aware
  envelope 与真实残差分桶，而不是继续调 veto。默认栈不变。

### 特征对比：绝对坐标 vs 相对特征（2026-11-21）

同一批 6536 条训练转移（100 个终止）上，只改状态表示，规则学习器
不变；在 120–124 的 held-out 终止状态（5 个）上比较：

| 臂 | 终止覆盖 | unknown | 假阳 | 规则 |
|---|---:|---:|---:|---|
| raw | **4/5** | 1 | 0 | `|f3|>0.176 AND |f2|<0.065`；`|f0|>0.499` |
| raw + 成对差 | **4/5** | 1 | 0 | 与 raw 完全相同 |
| 仅成对差 | **0/5** | 5 | 0 | 无 |
| raw + 归一化差 | **4/5** | 1 | 0 | 与 raw 完全相同 |

判定：**成对/归一化相对特征在当前观测编码下是冗余的**。raw 坐标
本身已经包含“到障碍的横向距离”“到开口的纵向偏移”等相对量；
规则学到的 `对齐 + 区间外` 已经是关系谓词组合。只留差值会丢掉
边界/绝对参照，直接失效。因此不为死亡规则默认打开 `pairwise`。

**但这不证明“相对特征无用”**：当前所有世界共享同一观测坐标框架，
没有帧平移/缩放/绝对坐标变化，无法区分“绝对阈值”与“关系不变量”。
下一步要构造**换帧/换尺度**的通用世界，测关系谓词（区间、包含、
顺序、重叠）是否比坐标阈值更可迁移；再用跨世界模式库测样本效率。
若换帧后关系臂仍无优势，瓶颈就不在特征语言，而在规则→行动/
失败→规则/未知→求知的接线。

### 模式库：结构迁移 vs 阈值校准（2026-11-21）

合成关系任务：`(|z0|<a AND |z1|>b) OR (|z2|>c)`；每个世界套不同的
逐坐标仿射观测帧。源世界 8 个，测试世界 6 个；比较从零学全部坐标
（scratch）、只复用模式库抽出的关系维度（schema）、逐世界标准化
（normalise）、两者结合。

- 模式库从源世界正确抽出了 `dims=(0,1)` 与 `(2,)` 两个死亡模式，
  schema 为 `{0,1,2}`；**结构发现成立**。
- 但样本效率只在小预算有小幅提升：k=5 覆盖 **0.219 vs 0.164**，
  k=20 **0.228 vs 0.191**；k=10 持平，k=50/100 没有稳定优势；
  各臂假阳都高（合成任务需要 4 个文字，阈值仍要本地拟合）。
- **判定：维度/模式复用 ≠ 阈值复用。** 模式库只告诉系统“看哪几个
  关系”，没有告诉它“边界在哪”。若继续这条线，需要存**归一化后的
  阈值先验/模板**，而不只是 dims；否则瓶颈在规则→行动/失败→规则，
  不在模式检索。

默认栈不变；`pattern_library.py` 与探针保留为通用实验工具。

### 反事实失败：终止状态规则本身覆盖得比计划级读数好（2026-11-21）

`counterfactual_failure_probe.py` 在 refine 世界运行真实 search，记录全部
候选计划，对每个计划做 oracle 首死步，并直接分类其**真实终止状态**：

- refine 120：3 个决策 / 96 个候选，真实终止状态 **0 missed / 1 covered**；
- test 122：1 个实际终止 + 1 个反事实终止，源规则都漏掉；
- failure 臂没有正例可加，random/all-terminal 臂也不改变 test。

合起来看：**死亡规则在真实终止状态上的覆盖比在“预测计划”上的读数好得多。**
候选计划探针的 2086 个 plan-level FN 里，很大一部分不是终止状态规则没覆盖，

杠杆是模型误差包络（`classify_death(include_margin=True)`），而不是继续
往规则里灌终止正例。

### 模型误差包络：近死亡当死亡（2026-11-21）

H=6 小样本筛选（35 决策/2240 候选）看起来很有希望：margin 0.01
把 recall 从 0.875 推到 0.976、selected_missed 4→1，且 FP 为 0。
但全量 H=8 暴露了精度-召回权衡：

| 口径 | 决策/候选 | recall | FP rate | selected_missed | tri_later | 动作对比 |
|---|---:|---:|---:|---:|---:|---:|
| exact death | 85/21760 | 0.798 | **3.0%** | 12 | **8** | **6/7** |
| margin 0.01 | 85/21760 | **0.884** | 9.6% | **7** | 4 | 4/7 |

- 召回 +8.6pt，但假阳从 3.0% 升到 9.6%（约 3 倍），
  selected_missed 12→7。
- 净选择收益反而下降：tri_later 8→4，selected survives 50→48；
  动作对比 6/7→4/7。
- 首死步 exact 0.693→0.331，within-1 基本不变（0.81）。
- H=6 的 0 FP 是小样本乐观偏差；全量结果才是裁决。
- **判定：near-death 当硬死亡不采纳。** 精确死亡侧的高精度更有价值；
  下一步把 near-death 当作**软风险/unknown**（不硬否决），或保持
  exact 精度转向模型误差/求知。margin 0.03 不再全量跑。

### 确认集与近死亡软风险：剩余 gap 是模型预测（2026-11-21）

独立确认集 123–126（68 决策 / 17408 候选）：

| 口径 | recall | FP rate | selected_missed | tri_later | selected survives |
|---|---:|---:|---:|---:|---:|
| exact death | 0.759 | **0.26%** | 10 | **10** | **45**（baseline 35） |
| margin 0.01 | **0.905** | 7.7% | **4** | 8 | 43 |

- 两个独立世界集（120–124、123–126）方向一致：margin 提高召回，
  但假阳上升，**净选择收益反而低于 exact death**。
- near-soft penalty（0.05/0.2/1.0）的选择指标与 exact **完全相同**；
  被选计划的 near 步数只有 ~0.5。near 带不是失败点。
- **漏检终止诊断**：确认集 10 个 selected miss 中，6 个真实终止状态
  是 exact death、4 个是 near。也就是说，**规则本身覆盖了真实终止，
  但 `f` 把预测状态推到了边界外/近边界之外**；planner 看到的是预测
  状态，于是静默。
- **判定：剩余 gap 是模型预测/状态访问问题，不是规则覆盖或阈值
  精度问题。** 继续加终止正例、调 margin、near penalty 都不会有
  稳定收益。下一杠杆是模型误差/支持度感知的信任（predicted state
  的 OOD/残差 → unknown/soft risk/inquiry）。

### 决策相关不确定性：0 个 decision-relevant miss（2026-11-21）

`planner_rollout_quality` 新增 `margin_analysis`：按 top1/top2 动作
分数差分桶，并记录 regret（选中计划真实存活 vs oracle-best）与
one-action-only。**修正 seed 缓存 bug 后，多 seed 结果并不一致：**

| seed | selected miss | decision-relevant | regret max | selected / oracle survives | plan recall | FP rate |
|---|---:|---:|---:|---:|---:|---:|
| 100 (120–124) | 12 | **0** | 0 | **50 / 50** | 0.798 | 3.0% |
| 100 (123–126) | 10 | **0** | 0 | **45 / 45** | 0.759 | 0.26% |
| 101 (120–124) | 15 | **10** | **6** | **54 / 64** | 0.756 | 1.2% |
| 102 (120–124) | 0 | **0** | 0 | **50 / 50** | **1.000** | 7.2% |

- seed 100/102：planner 已经选了 oracle-best；剩余 miss 是
  unavoidable（H=8 内所有候选都死）或 one-action-only，regret=0。
- **seed 101 是反例**：10 个 decision-relevant miss，选中存活比
  oracle 少 10；miss margin 横跨小/中/大桶（4/5/5），高 margin 桶
  的 regret 更大（mean 1.125）。这些 miss 的真实终止状态都是
  exact death，规则覆盖了真实终止，但预测状态漂移，且存在存活
  替代计划。
- **seed 101 的 oracle-best 归因**：10 个 decision-relevant miss 中，
  **oracle-best 计划 10/10 是 feasible**（death veto **0**），
  **10/10 被 score 排在致命计划后面**（score misrank **10**），
  mean score gap 0.053；seed 102 的 oracle-best ranked-first 47/47。
  也就是说，seed 101 不是死亡规则 veto 错，也不是规则覆盖不足，
  而是 **hazard/value score 把存活计划排在致命计划后面**。
- **固定 margin envelope 被多 seed 否决**：seed 101 envelope 的
  decision-relevant 仍为 10、selected survives 54→52；seed 102
  selected survives 50→45、regret_nonzero 5。envelope 提高标签
  recall，但不修 score misrank，还会 veto 安全计划。
- **判定：seed 101 的主瓶颈是 score 排序/校准，不是 death recall，
  也不是 state prediction depth。** 下一步做 score component 诊断
  （risk/value/curiosity 哪一列把存活计划排后），再做 calibration
  或 conservative lower bound；seed 100/102 的晚期状态仍指向候选集/
  时域/探索。两条瓶颈并存，谁是主瓶颈取决于模型。

**归纳形式扩展（2026-11-20）：成对坐标差**。根稀疏的一个来源是绝对阈值
贴在训练分布边缘。归纳文法新增纯代数坐标：

```text
d_ij = x_i − x_j      （所有 i<j；索引无语义，共 21 个新坐标）
```

谓词仍是 `d_ij < c / > c`，阈值仍取训练分布分位数；不读取任何任务常量。
候选池按单变量 z 截到 240 条再进入 AND/OR 搜索（组合步是平方级）。
`--no-pairwise-features` 关闭，路径与旧文法一致。A/B（新基准、3 种子）
与根激活探针进行中。

**跨世界激活验证（2026-11-20，已实现）**：上一条的门槛仍用训练流的
episode 切分，无法发现“只在训练世界出现”的根。新增
`--rule-validation-seed S --rule-validation-frames N`：从独立世界 S
采集 N 帧，**只用观测、不用标签、不进训练**，覆盖率门槛在这条流上
测量（`FeatureRuleBank.induce(coverage_x=...)`）。世界 S 与训练
（100–107）、评测（120–139）都不重叠。A/B（S=150、600 帧、
c=1%/p=2%）进行中。

**首轮（600 帧）结果**：生存配对 +23.8（SE 36.1，2/3 正向，主要来自
